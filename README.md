# NftMerge

NftMerge enables multi-tenancy and real-time data processing across decentralized networks, featuring auto-scaling service architecture.

NftMerge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftMerge.git`
2. `cd NftMerge`
3. Install in editable mode: `pip install -e .`

## Configuration

NftMerge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
